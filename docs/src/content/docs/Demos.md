title: "Demos"
---

These demo apps show Shadcn Admin Kit in action. The e-commerce and email demos run entirely in the browser with fake data (powered by [FakeRest](https://github.com/marmelab/FakeRest)): feel free to explore and modify the data, it resets each time you reload the page.

## E-Commerce

The admin of an imaginary poster shop: orders, products, categories, customers and reviews, with a dashboard. It showcases the data table, filters, forms, references and the login page.

- Live demo: [marmelab.com/shadcn-admin-kit/demo](https://marmelab.com/shadcn-admin-kit/demo/)
- Source: [src/demo](https://github.com/marmelab/shadcn-admin-kit/tree/main/src/demo)

## Email Client

A mail client inspired by the shadcn/ui Mail example: folders and categories with unread counters, a searchable list of conversations, threads with replies, labels, and undoable actions (archive, junk, trash). It uses a custom layout and sidebar, and adapts to mobile screens.

- Live demo: [marmelab.com/shadcn-admin-kit/demo-mail](https://marmelab.com/shadcn-admin-kit/demo-mail/)
- Source: [src/demo-mail](https://github.com/marmelab/shadcn-admin-kit/tree/main/src/demo-mail)

## CRM

Atomic CRM, a full-featured CRM built with Shadcn Admin Kit: contacts, companies, deals, tasks and notes.

- Live demo: [marmelab.com/atomic-crm-demo](https://marmelab.com/atomic-crm-demo/)
- Source: [marmelab/atomic-crm](https://github.com/marmelab/atomic-crm)
